# Storylines: NNTS Profile Search & Rapid Switch

> **Recommendation**: Storyline A ("Interactive Catalog Search & Rapid 3-Profile Sprint") — because it directly visualizes the exact user workflow requested: finding and filtering a Chromium profile via interactive search, assigning it, and then executing sub-second switches across 3 profiles with live window feedback.

---

### Assumptions
- **Length**: 18.0 seconds (540 frames at 30 fps)
- **Aspect**: 16:9 Landscape (1920×1080)
- **Audio**: Measured silent delivery bed (with on-screen tactile visual sound cues).
- **Brand Rules**: Space Grotesk Bold, strict lowercase `caps lock`, 100% English copywriting.

---

### Storyline A: Interactive Catalog Search & Rapid 3-Profile Sprint (Recommended)
- **Device & Form**: Worked example + continuous transformation.
- **In two sentences**: A user searches through their Chromium profile library in the NNTS HUD, filters for "Client", and then demonstrates the lightning-fast `caps lock + c + 1..3` switching loop across Personal, Work, and Client profiles without ever touching `Cmd+Tab`.
- **First two seconds**: Floating dark glass HUD bezel open with profile avatars and active search bar: *"Find & Switch Chrome Profiles"*.
- **Beats**:
  1. `0.0s – 7.5s`: Profile Catalog & Live Search — `caps lock + c` opens HUD, user types *"client"*, avatar filters in real-time, window elevates.
  2. `7.5s – 14.5s`: Rapid 3-Profile Switching — Direct sequential jumps across Profile 1 (Personal) → Profile 2 (Work) → Profile 3 (Client) in 1.2s.
  3. `14.5s – 18.0s`: Payoff & Call to Action — NNTS mascot, macOS speed metric, and download action.

---

### Storyline B: The Cluttered Desktop Race
- **Device & Form**: Life before and after + match cuts.
- **In two sentences**: A race between default macOS `Cmd+Tab` cycling through 25 windows vs. NNTS profile search and instant direct-index keys.
- **First two seconds**: Frantic tab cycling through identical Chrome icons.
- **Beats**: `Cmd+Tab failure → NNTS search filters instant profile → 1-2-3 triple jump → Win & End card`.

---

### Storyline C: Typographic Hotkey Sprint
- **Device & Form**: Type carries the argument + tactile keycaps.
- **In two sentences**: Bold typographic presentation with mechanical keycaps slamming down sequentially as profiles switch with zero latency.
- **First two seconds**: Giant kinetic type: *"3 CHROME PROFILES. 1.2 SECONDS."*
- **Beats**: `Search reveal → 3 keycap slams → Active window cascade → CTA`.
