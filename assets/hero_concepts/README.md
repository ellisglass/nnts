# Xomsky Hero Concepts Catalog

Коллекция финальных эталонных ассетов для Hero-баннера Xomsky (16:9), выверенных в соответствии с каноном маскота (`khomyak_reference_studio_light.png`) и рекомендациями UX/HCI-аудита.

---

## 1. Concept A — The macOS Desk Pilot
- **Файлы:** `concept_a_desk_pilot.png` / `concept_a_desk_pilot.jpg`
- **Сюжет:** Канонический Хомяк сидит перед открытым MacBook Pro Space Gray. На чистом экране macOS Sequoia парит HUD с логотипом Chrome и 4 профилями (`Personal`, `Work`, `Family / Partner`, `Side Project`). Белая лапка с подушечками касается подсвеченной клавиши `Caps Lock`.
- **Смысловой акцент:** Разрушение абстрактного вакуума, показ живого контекста системы Mac.

## 2. Concept B — The Multi-Profile Maestro
- **Файлы:** `concept_b_profile_maestro.png` / `concept_b_profile_maestro.jpg`
- **Сюжет:** Канонический Хомяк в спокойной позе (лапки сложены под подбородком) в окружении 4 парящих окон браузера (`[1: Work]`, `[2: Family / Partner]`, `[3: Personal]`, `[4: Side Project]`). Внизу по центру расположен аутентичный физический кейкап `caps lock` от MacBook с выключенным (unlit) индикатором.
- **Смысловой акцент:** Решение главной боли пользователей macOS — мгновенное разделение и подъем окон нужного профиля браузера.

## 3. Concept C — Apple Bento Grid Hero
- **Файлы:** `concept_c_bento_grid.png` / `concept_c_bento_grid.jpg`
- **Сюжет:** Модульная Bento-сетка в стиле презентаций Apple. 
  - Центр: крупный план канонического Хомяка.
  - Верх-лево: Chrome Profile Switch с бейджем `Caps + C + 1..4`.
  - Верх-право: Copy-on-Select с читаемым текстом и бейджем `✔ Copied!`.
  - Низ-лево: Instant App Switcher с иконками Terminal, Finder, Notes, Spotify.
  - Низ-право: Home Row клавиши `T`, `F`, `N`, `S` («Caps + Первая буква»).
- **Смысловой акцент:** Исчерпывающая презентация сразу всех 3 ключевых фич продукта на одном экране с нулевой когнитивной перегрузкой.

## 4. Concept D — The Invisible Flow
- **Файлы:** `concept_d_invisible_flow.png` / `concept_d_invisible_flow.jpg`
- **Сюжет:** Макро-фотография угла клавиатуры Apple Magic Keyboard. Клавиша `Caps Lock` мягко подсвечена лазурным неоном. Обе белые лапки Хомяка с розовыми подушечками лежат на клавиатуре. Никаких плашек и текста — чистый визуальный минимализм.
- **Смысловой акцент:** Тактильность, аппаратная интеграция и скорость (muscle memory).
